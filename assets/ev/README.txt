Nissan LEAF interior cabin texture

Source: "Nissan Leaf INT put into gear and drive various speeds. Pedestrian
warning mode on." by martian, https://freesound.org/people/martian/sounds/512492/
License on source page: Creative Commons Zero 1.0.

The bundled leaf_cabin_texture_i16.bin is a transformed 80-second segment
(210–290 seconds) derived from the public Freesound MP3 preview. It was
band-limited to 115–3500 Hz, normalized and converted to 44.1 kHz stereo
interleaved signed 16-bit PCM. research/leaf2017/prepare_texture.py reproduces
the processing. The source does not give model year, speed, microphone type,
gain or calibration, so this recording supplies only irregular cabin texture.
The 2017 motor speed and loading are generated separately at runtime.
